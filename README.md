# Tarini Akula · Personal Portfolio

Personal portfolio website of Tarini Akula: Salesforce development and administration, data analytics, business and systems analysis, and AI assisted project work.

Live site: https://tariniakula01-pixel.github.io

## Structure

- `index.html` — homepage: hero, about, what I do, featured projects with working filters, Salesforce and AI, skills, certifications, approach, contact
- `projects/k12.html` — K 12 Student Data Analytics project page, with an evidence view that shows the same KPI values verified in Python, SQL, and Excel
- `projects/healthcare.html` — Healthcare Operations Analytics case study page, with a deliverables table linked to repository files
- `projects/caseassist.html` — CaseAssist project page, with implementation status and a labeled demonstration walkthrough
- `assets/styles.css` — the full design system: deep navy, warm white, copper, and deep teal, with Spectral, Public Sans, and IBM Plex Mono
- `assets/script.js` — project filters, the About longer version toggle, the K 12 results explorer, the CaseAssist classifier run, the Healthcare requirements explorer, and the CaseAssist walkthrough controls
- `assets/tarini-akula.jpg` — the profile photograph in the homepage hero
- `assets/resumes/` — the three resume PDFs linked from the Contact section, converted from the base resume documents without content changes

## Stack

Plain HTML, CSS, and JavaScript. No framework, no build step, no backend. Hosted on GitHub Pages from this repository.

## Updating the site

Edit the HTML, CSS, or JavaScript files and push to the main branch. GitHub Pages republishes automatically within a few minutes.
