# Tarini Akula · Portfolio

Personal portfolio site for Tarini Akula, hosted on GitHub Pages at https://tariniakula01-pixel.github.io

## Structure

The site is a single self-contained page. All styling and interaction code lives inside `index.html`; there is no build step.

- `index.html` — hero, experience, featured projects with three working demonstrations (K-12 results explorer, CaseAssist classifier simulation, Healthcare requirements explorer), certifications, resume downloads, contact
- `assets/tarini-akula.jpg` — the profile photograph in the hero
- `assets/resumes/` — the three resume PDFs linked from the Resume section
- `sitemap.xml`, `robots.txt` — search engine files

## Stack

Plain HTML, CSS, and JavaScript. No framework, no build step, no backend. Hosted on GitHub Pages from this repository.

## Updating the site

Edit `index.html` and push to the main branch. GitHub Pages republishes automatically within a few minutes.

## Notes

- The K-12 and Healthcare projects use simulated practice datasets; the sites and repositories say so.
- Certification verification links point to the owner's Trailhead profile for the two Salesforce certifications. Copado and Databricks have no public verification links.
